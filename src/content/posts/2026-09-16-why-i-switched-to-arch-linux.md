## Why Arch?

The biggest reason was curiosity, control, minimalism and learning experience. Arch let's me configure almost anything in the system which is exactly why i switched from windows

## The Install

I used `archinstall` for easier setup. I also use btrfs for my filesystem, i also use niri + noctalia shell for my desktop environment. 

## What I Use It For

- Daily driver for all development work
- `yay` as AUR helper
- Timeshift for system backup
- Easy firewall setup & VPN config

## The Rough Edges

Setting up for the first time was the hardest, i broke the partitions easily. I also get package conflicts here and there especially after system updates( i use timeshift before every system update now). I also had an issue with mounting my second drive to the system which i resolved with some tinkering with the config files

## Would I Recommend It?

I would recommend Archlinux to all those that prefer to have a granular control over there system and also for those that just want to switch away from windows, i would recommend starting with a more friendly operating system like `Ubuntu`
