GitHub Mobile keeps my repos within reach.

## What it replaces

I use it to respond to issues, review pull requests, and check CI status while away from my desk.

## Highlights

- Review and merge pull requests
- Manage issues and notifications
- Check build status

It is not a replacement for a real workstation, but for keeping a project moving between desk sessions it is hard to beat.
